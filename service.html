Setup needed

This app needs to be connected to your shared Firebase project. Paste the project config into the firebaseConfig block near the top of this file's script.

1. Create a free project at console.firebase.google.com
2. Add a Web App, copy the config object
3. Enable Firestore Database + Storage
4. Enable Authentication → Email/Password (and Anonymous, for the public form)
5. Add a user for each teammate
6. Paste the config into this file
7. Re-upload to GitHub
