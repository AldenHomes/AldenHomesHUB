Tasks run one after another, top to bottom. To overlap a task with the one above it, click its Starts setting and type how many days to overlap — the tasks below still follow it. You can also link it to another task: it can start the same day, or follow that task with a gap or an overlap. Linked tasks move together and don't push the ones below later.

A template is the order of tasks for a type of house. Each task's days and vendor come from the Tasks tab, so changing your painter there changes it in every template at once. Only change days or the vendor here when this type of house is different from the usual — it gets a small tag you can click to go back to the usual. Editing a template affects houses started after the edit; schedules already built keep what they have.
